# NEXUS AI VIP AGENCY

Bu proje, kurumlar için özel yapay zeka çözümleri sunan bir VIP Yapay Zeka Ajansı web sitesidir. Next.js ve Tailwind CSS kullanılarak oluşturulmuştur.

## Özellikler

- **VIP Tasarım:** Obsidian Dark teması, modern cam efektleri (glassmorphism) ve teknolojik renk paleti.
- **Canlı ROI (Yatırım Getirisi) Hesaplayıcı:** Kurumsal müşterilerin tahmini yıllık tasarrufunu hesaplayan dinamik modül.
- **Canlı AI Test Terminali (Playground):** Potansiyel müşterilerin yapay zeka modellerini test edebileceği etkileşimli alan.
- **Otonom Ajan Mimarisi:** Şirket operasyonlarını otomatikleştiren otonom yapay zeka ajan sistemlerinin sergilenmesi.

## Teknoloji Yığını

- **Frontend:** Next.js, Tailwind CSS, Lucide Icons
- **Backend (Dağıtım):** Vercel (ücretsiz ve sınırsız yayınlama)
- **AI İşleme (Gelecek Planı):** Python FastAPI, LangChain
