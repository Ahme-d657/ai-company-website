# TAÇ AI VIP AGENCY

Bu proje, kurumlar için özel yapay zeka çözümleri sunan Taç AI markasına ait VIP Yapay Zeka Ajansı web sitesidir. Next.js ve Tailwind CSS kullanılarak geliştirilmektedir.

## Özellikler

- **VIP Tasarım:** Obsidian Dark teması, modern cam efektleri (glassmorphism) ve neon ışıklandırma detayları.
- **Canlı ROI Hesaplayıcı:** Kurumsal müşterilerin yıllık maliyet tasarrufunu hesaplayan etkileşimli modül.
- **Canlı AI Test Terminali (Playground):** Taç AI altyapısının hızını ve çıktılarını deneyimleme alanı.
- **Otonom Ajan Mimarisi:** Şirket operasyonlarını otomatikleştiren yapay zeka sistemleri.

## Teknoloji Yığını

- **Frontend:** Next.js, Tailwind CSS, Lucide Icons
- **Deployment:** Vercel (7/24 kesintisiz ve ücretsiz)
- **Backend:** Python FastAPI, LangChain / CrewAI
